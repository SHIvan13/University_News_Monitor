# University_News_Monitor
Программа мониторинга новостей с сайтов вузов (МИРЭА, РЭУ, КФУ)
Для работы необходим Python 3 и сторонние библиотеки requests, beautifulsoup4 и pandas. urllib, sqlite3, json, time и logging входят в стандартную библиотеку Python.
## Установить зависимости можно командой:
`pip install -r requirements.txt`

Файлы parser_mirea.py, parser_rea.py и parser_kfu.py должны находиться в каталоге parsers, если импорты main.py оставлены без изменений. Файл db_func.py и config.json должны быть доступны из рабочего каталога.
1.	Проверить наличие Python 3 и файлов проекта.
2.	Установить зависимости командой pip install -r requirements.txt.
3.	Проверить значения параметров в config.json.
4.	Из корневого каталога проекта выполнить python main.py.
5.	Проверить консоль, базы данных, send_list.txt и monitor.log.
6.	Для остановки программы нажать Ctrl+C.

При использовании относительных путей базы данных, журнал и файл рассылки создаются относительно текущего рабочего каталога. Рекомендуется запускать main.py из корня проекта.
